# UAV Safe RL — v4 to v9 Experimental Project

Executable research scaffold for 3-D point-mass UAV navigation using SAC,
dynamic obstacles, event triggering, and a CBF-style safety filter.

The version structure follows the supplied project report/PPT. The code is an
implementation scaffold, not the original source code of another researcher.
Fresh results must be generated by running the experiments.

Versions:
- v4: five-obstacle baseline
- v5: extended training + TTC modification
- v6: curriculum with replay-buffer reset
- v7: curriculum with replay-buffer continuity
- v8: obstacle-spacing correction
- v9: corrected SAC training; CBF is used at deployment rather than substituting
  the policy action during learning

Quick start:
    pip install -r requirements.txt
    python scripts/run_smoke_test.py
    python versions/v4_baseline/train_v4.py
    python versions/v4_baseline/evaluate_v4.py

Full SAC training is computationally expensive.
Fresh outputs go to logs/, checkpoints/, and results/.
Reference values from the supplied report/PPT are kept separately in
results/reference_report_results.csv.
